# Blogs Frontend

## Purpose
This package contains the Next.js frontend for Zeon Blog.

## What Lives Here
- App Router pages for public blog browsing, authentication, writing, dashboards, and profiles.
- Reusable UI components grouped by feature and layout concern.
- Client API helpers, session utilities, state providers, and frontend tests.
- Public static assets used by the application shell and components.

## Navigation
- Start with the app layout to understand providers and global UI.
- Use route folders to find page-level behavior.
- Use component folders for reusable presentation and interaction code.
- Use client API helpers to understand frontend/backend contracts.

## Safe Setup Notes
Runtime configuration should be supplied outside committed markdown. Do not document concrete hosts, private access material, or deployment-specific values in public docs.

## Validation
Run the package build and frontend test suite after UI or API-client changes. Smoke-test important pages after behavior changes.
